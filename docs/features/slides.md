# Markdown 演示

> **状态**：已实现（2026-10-29，2026-11-01 更新）。
>
> **本文回答**：如何把任意 Markdown 笔记直接变成全屏演示页？H1/H2/H3 如何映射？页眉、页码、页内滚动和全屏如何工作？哪些行为明确不支持？

## 1. 功能概览

- 任意 Markdown 笔记都可以直接演示，**不需要添加 `---`**。
- H1 单独成为主题页；H2 成为正文页；H3 子标题各自成为独立正文页。
- H2 下没有 H3 时，H2 的所有内容放在同一页；H2 在第一个 H3 之前有自己的内容时，这段内容单独成页。
- H2 后直接跟 H3 时，不生成只有 H2 标题的空页。
- H4–H6 留在当前正文页内，作为小标题。
- 单页装不下时，正文区支持上下滚动；页眉、页码和进度条保持固定，不再缩小字号。
- 正文图片按预览窗口宽度的 80% 显示，高度按原始比例缩放；图片过高时随正文一起滚动。
- 使用 Obsidian 自带渲染器，代码块、公式、Mermaid、Callout、图片、嵌入、表格、任务列表与阅读视图一致。
- 内容区铺满整个屏幕（没有画布边距和圆角），主题页/正文页区分，页码、进度条、淡入翻页。打开演示时自动进入全屏；浏览器拒绝时保留铺满窗口的 Modal。按 `Esc` 直接退出演示。
- 命令、Ribbon、文件右键菜单三个入口。

特性 ID：`slides`。首次安装默认关闭，需要在插件设置中手动启用。

## 2. 入口

| 入口 | 行为 |
|---|---|
| 命令面板 → 演示当前笔记 | 演示当前活动的 Markdown 笔记 |
| 左侧 Ribbon → 演示当前笔记 | 同上 |
| 文件列表右键 → 演示此笔记 | 演示被右键的 Markdown 笔记，不需要先打开它 |

没有活动笔记、活动文件不是 `.md`、或笔记没有可渲染内容时，只显示 Notice，不打开演示。

## 3. 分页规则

| Markdown 结构 | 演示页 |
|---|---|
| `# 一级菜单` | 主题页：只显示 H1、章节序号和强调线 |
| H1 之后、第一个 H2 之前的内容 | 正文页：默认无页眉，正文为这段内容（开启页眉时显示 H1） |
| `## 二级菜单` | 正文页：H2 作为页标题；没有 H3 时，H2 下所有内容都在这一页 |
| H2 下、第一个 H3 前的正文 | 单独正文页：H2 + 这段内容；没有这段正文时不生成只有 H2 标题的空页 |
| `### 三级菜单` | 每个 H3 单独一页：H3 作为页标题，内容延续到下一个 H3 或 H2 |
| H4–H6 | 留在当前正文页内，作为小标题 |
| 单页装不下 | 正文区可上下滚动；页眉、页码和进度条保持固定 |
| 独立的 `---` / `***` / `___` | 手动分页；不加也能按标题分页 |
| 第一个标题之前的内容 | 引言正文页：默认无页眉（开启页眉时使用 frontmatter `title` 或文件名） |
| 没有 H1 | 不生成主题页，H2/H3 直接作为正文页 |
| 没有任何标题 | 整个笔记作为一页正文 |

示例：

```md
# 主题 A

## 子主题 A1

A1 概述

### 细节 1

正文 1

### 细节 2

正文 2

#### 补充

补充说明

## 子主题 A2

正文 A2

---

正文 A2 续

# 主题 B

## 子主题 B1

正文 B1
```

生成：

1. 主题页：主题 A
2. 正文页：子主题 A1（H2 的直接内容）
3. 正文页：细节 1
4. 正文页：细节 2（`#### 补充` 留在这一页）
5. 正文页：子主题 A2
6. 正文页：子主题 A2（`---` 手动分页）
7. 主题页：主题 B
8. 正文页：子主题 B1

H2 有直接正文时才单独占一页；如果 H2 后直接跟 H3，不会生成只有 H2 标题的空页。H3 页的页眉仍是可选的 `一级-二级`，不包含 H3 本身。默认不显示页眉；开启后每个正文页顶部显示对应的一级和二级标题。

单页装不下时，不按高度自动拆页，也不缩小字号，而是保留这一页并让正文区滚动：

1. 分页只由 H1/H2/H3 和手动 `---` 决定，不受窗口高度影响。
2. 页眉、页码和底部进度条固定在页面上，只有正文区滚动。
3. 鼠标滚轮、触控板和滚动条都可以滚动正文；`↓` / `PageDown` 先向下滚动，到底后再翻下一页，`↑` / `PageUp` 反向同理。

```mermaid
flowchart LR
    File["当前 md 文件"] --> Read["cachedRead"]
    Read --> Strip["去除 frontmatter"]
    Strip --> Render["MarkdownRenderer 整篇渲染"]
    Render --> Blocks["顶层 DOM 分块"]
    Blocks --> Plan["planSlides<br/>H1 主题页 / H2 正文页 / H3 独立页"]
    Plan --> Slides["铺满屏幕的页面"]
    Slides --> Scroll["单页超出时正文区上下滚动"]
    Scroll --> Modal["全屏 Modal 演示"]
```

## 4. 设置

| 设置 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 显示正文页页眉 | 开关 | 关 | 打开后在正文页顶部显示 `一级菜单-二级菜单` |
| 页眉分隔符 | 文本 | `-` | 连接一级和二级标题；最多 3 个字符 |
| 显示页码 | 开关 | 开 | 页面右下角显示 `n / total` |
| 显示进度条 | 开关 | 开 | 窗口底部显示整体进度 |
| 配色 | 下拉 | 跟随主题 | 跟随 Obsidian 主题，或强制浅色/深色画布 |
| 翻页动画 | 下拉 | 淡入 | 淡入 / 无 |

设置修改后，下一次打开演示生效；演示期间设置页被全屏 Modal 遮挡，不需要实时重建。

## 5. 交互

| 操作 | 按键 / 方式 |
|---|---|
| 下一页 | `→` `Space`，或点击屏幕右侧三分之一；`↓` / `PageDown` 在当前页滚到底后翻页 |
| 上一页 | `←` `Shift+Space`，或点击屏幕左侧三分之一；`↑` / `PageUp` 在当前页滚到顶后翻页 |
| 页内滚动 | 鼠标滚轮、触控板、拖动正文滚动条；`↓` / `↑` 少量滚动，`PageDown` / `PageUp` 大幅滚动 |
| 首页 / 末页 | `Home` / `End` |
| 页码 | 按 H1/H2/H3 与 `---` 分页后的实际页数；不按内容高度自动拆页 |
| 退出演示 | `Esc`（全屏状态下同样直接退出） |
| 移动端 | 正文区可上下拖动滚动；翻页使用左右屏幕按钮，v1 不做滑动手势 |

点击链接、按钮、输入框、视频、iframe、Callout 折叠标题时不翻页；有文本选区时也不翻页。拖动正文滚动条时不会触发翻页。

## 6. 渲染与限制

### 6.1 渲染方式

1. 读取笔记，使用 `metadataCache` 的 frontmatter 位置去除 YAML；缓存不可用时用正则回退。
2. 用 `MarkdownRenderer.render` 把整篇笔记渲染到一个隐藏容器。
3. 读取渲染结果的**顶层子元素**：`H1`–`H6` 作为标题，`HR` 作为手动分页，其余作为正文块。
4. `planSlides` 生成主题页/正文页计划：H1 主题页、H2 正文页、每个 H3 独立正文页。
5. 把原始 DOM 节点移动进铺满屏幕的页面；H4–H6 和正文块跟随当前 H3/H2 页。
6. 单页超出时正文区出现纵向滚动，不改变字号。
7. 页眉、页码、进度条不参与滚动；翻页时当前页滚动位置重置到顶部。

### 6.2 已知限制

- 演示是**快照**：演示期间编辑笔记不会实时更新，关闭后重新打开即可。
- frontmatter 不显示；脚注跟随整篇渲染，通常落在最后一页。
- 如果某个第三方插件在 `MarkdownRenderer` 完成后才异步添加顶层内容，这些内容可能落在当前页而不是新的分页；已在页面内的异步内容不受影响。
- 如果 HTML 块把标题包在 `<div>` 内，标题不会被识别为分页点。
- 分页只由标题层级和手动 `---` 决定；单页内容再长也不会自动拆成多页，需要滚动阅读。
- 演示期间调整窗口会重新计算基准字号，但不会改变页数和分页。
- 特别高的图片、Mermaid 图、视频或单行超宽表格可能需要页内滚动；图片固定为视口宽度的 80%，高度按比例缩放，表格和代码块本身也保留横向滚动。
- 不生成 `.pptx` / PDF 文件。

## 7. 生命周期

- 启用：注册命令、Ribbon 和 `file-menu` 监听；不常驻渲染任何内容。
- 打开演示：按需读取文件、渲染、创建 Modal。
- 关闭 Modal：释放渲染组件、DOM 监听和全屏状态。
- 关闭特性：`ctx.unload()` 移除命令/Ribbon/事件，并通过 cleanup 关闭已打开的 Modal。
- 快速开关：由 `FeatureManager` 串行化，不重复注册。
- 插件卸载：走同一清理路径。

## 8. 错误与边界

| 场景 | 行为 |
|---|---|
| 没有活动笔记 / 非 `.md` | Notice，不打开 Modal |
| 空笔记或只有 frontmatter | Notice“没有可演示的内容” |
| 读取或渲染失败 | 关闭 Modal，记录日志，Notice 错误信息 |
| H1 后直接跟正文 | 主题页 + 正文页（开启页眉时页眉为 H1） |
| 首个标题前有正文 | 引言正文页（开启页眉时用 frontmatter `title` 或文件名） |
| 没有 H1 | 不生成主题页，H2/H3 正文页（开启页眉时页眉只有 H2） |
| 没有标题 | 单页正文（开启页眉时用笔记名） |
| H2 后直接跟 H3 | 不生成只有 H2 标题的空页，直接从 H3 页开始 |
| H2 下没有 H3 | H2 的所有内容放在同一页；超出时滚动 |
| 连续 `---` | 不产生空页 |
| 代码块/公式中的 `#`、`---` | 不会被误判为标题或分页 |
| 图片/表格/代码过长 | 保留当前页，正文区纵向滚动；表格和代码块可横向滚动 |
| 连续执行演示命令 | 关闭旧 Modal，打开新 Modal |
| 特性关闭 / 插件卸载 | 关闭 Modal，移除所有入口 |
| 全屏请求失败 | 忽略，保留 Modal 全屏样式 |

## 9. 手动验收

1. 在测试 Vault 准备第 3 节的示例笔记，启用特性，运行“演示当前笔记”。
2. 确认 H1 单独主题页、H2 有直接正文时单独一页、每个 H3 各自一页；H2 后直接跟 H3 时没有只有标题的空页。正文页默认不显示页眉；开启页眉后确认显示 `主题 A-子主题 A1`。同时确认没有添加 `---`。
3. 确认 H1 后直接正文生成独立正文页，不混进主题页；H4–H6 留在所属 H2/H3 页内。
4. 验证代码块、公式、Mermaid、Callout、图片/嵌入、表格、任务列表。
5. 在 H2 内容中加 `---`，确认手动分页；连续 `---` 不产生空页。
6. 写超长正文、连续图片、长列表、长表格和长代码块，确认页面不被裁切，正文区可上下滚动；页眉、页码和进度条保持固定。确认字号不会因为内容变长而自动缩小，图片宽度约为预览窗口的 80%，高度没有拉伸变形。
7. 在有滚动条的页面按 `↓` / `PageDown`，确认先滚动、到底后才翻页；`↑` / `PageUp` 在顶部才回到上一页。拖动滚动条不会触发翻页。
8. 打开演示后确认内容铺满屏幕并自动进入全屏；按 `Esc` 直接退出演示。键盘、左右区域点击、屏幕按钮全部生效；点击链接/按钮不翻页。
9. 设置：开启/关闭页眉、分隔符改为 `›`、关闭页码/进度条、强制浅色、关闭动画。
10. 文件列表右键另一篇笔记，确认“演示此笔记”可用。
11. 演示中关闭特性，确认 Modal 关闭、命令/Ribbon/右键菜单消失；重新启用后只出现一次。
12. 重启 Obsidian，确认设置保留；重置特性后恢复默认。
13. 深色/浅色主题、系统减少动画、移动端按钮和触控滚动各走一遍。
14. 运行 `pnpm lint && pnpm typecheck && pnpm test && pnpm build`。

## 10. 设计取舍

| 选择 | 意图 | 代价 | 重新评估条件 |
|---|---|---|---|
| 整篇渲染后按 DOM 分区 | 复用 Obsidian 渲染，不写 Markdown 解析器 | 依赖顶层 DOM 结构；异步顶层节点可能漏分 | DOM 分区在真实插件组合下不稳定时 |
| H1/H2/H3 固定映射 | 一级主题、二级正文、三级子标题独立成页 | 不支持自定义层级；H4–H6 只能作为页内小标题 | 用户需要可配置分页层级时 |
| 全屏 Modal | 不修改核心、不注册视图，生命周期简单 | 不能并排预览、独立投影窗口、恢复工作区 | 需要长期打开的演示标签页时 |
| 按标题分页 + 页内滚动 | 页数稳定、可预测，不依赖窗口高度 | 长内容需要滚动，不能一屏完整展示 | 用户更希望长页自动拆成多页时 |
| 不导出 `.pptx` | 避免引入布局/导出引擎 | 不能直接交付 PowerPoint | 需要交付 `.pptx` 时另立导出特性 |

## 11. 非目标

- 导出 `.pptx` / PDF。
- 演讲者备注、缩略图总览、编辑时实时预览、双栏预览。
- 从光标处开始演示。
- 按窗口高度自动拆页或生成续页。
- 为适配单页而自动缩小字号。
- 可配置标题层级、自定义主题编辑器。
- 移动端手势翻页。
- 修改、移动或创建笔记。
